# Horizon islets (art lead, Blender, flat materials)

Distant island silhouettes for the horizon (QA pass 3, IS-20: every painting puts land on the horizon).
Rock sides, a domed grass cap, a thin sand rim and a few pine clumps. Flat toon colours, own colours.

| File | Built at (m) | Shape |
|---|---|---|
| islet-a.glb | 100 x 30 x 70 | low domed island, gentle slopes |
| islet-b.glb | 80 x 40 x 55 | headland with one steep cliff side (-X) |

The model floor (y = 0) is 3 m below the waterline: place the box floor at seaLevel - 3 x scale.
Intended for 5 instances at 900-1,300 m from the island centre, fogged. 1.4k triangles each. CC0.
