# Storybook cottages (painting palette)

Six recolours of the two CC0 Quaternius "Medieval Village" timber houses already in the library
(`quaternius/medieval-village-pack/fantasy-house_BH2XHWUNmF.glb` = a, `fantasy-house_dcPho4SUA3.glb` = b),
recoloured per material in Blender with colours sampled from `docs/art/hifi/08_poi_hoofington.png`.
See `_preview.jpg` (a-pink, a-cream, a-yellow, b-pink, b-cream, b-yellow).

| Part (material) | pink | cream | yellow |
|---|---|---|---|
| Plaster walls | #e8a3b0 | #fcdfba | #f2c84b |
| RoofTiles | #4b4960 slate | #ce5c55 terracotta | #5f6f8f blue slate |
| Wood / Wood_Light / Wood_Side | #7b4a2c / #a8703f / #c89a63 | same | same |
| Stone / Stone_Dark / Stone_Light | #b9ad9c / #cfc3b0 / #e6dccb | same | same |
| Windows | #9fd3ee | same | same |

Flat colours per material, no textures, so any texture-to-vertex-colour baker keeps them exactly
(colour = material base colour). Native size about 2.2 x 2.7-3.4 x 3.3-3.4 m, base at y=0; scale to the
building footprint as before. These replace the white/mint Kenney `city-kit-suburban` houses for the
island `house`/`cottage` props and Hoofington's pink/cream/yellow homes. Mix the three colours per house.
