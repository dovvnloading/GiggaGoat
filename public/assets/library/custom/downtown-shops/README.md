# Downtown Bleatsville shop set (Kenney city-kit-commercial, painting palette)

Eleven Kenney commercial buildings (CC0), the island's single building family, prepared in Blender to match
`docs/art/hifi/11_poi_downtown.png`:

- palette texture recoloured per part: pastel walls, cream trim/window frames/cornices, deeper-tone ground
  floor of the same hue, blue glass, white flower boxes with pink/purple/white flowers on every window;
- a shopfront added on the street side (glTF +Z) of the ground floor: framed display window with a warm lit
  shelf, wooden door, cream sign board (blank, for the shop name) and a striped awning with a valance;
- native Kenney units, base y=0; the game fits them to the collider box. Render with the model's own colours.
