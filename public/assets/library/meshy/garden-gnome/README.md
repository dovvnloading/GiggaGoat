# Garden gnome (Meshy community, CC0)

- `garden-gnome.glb`: classic red-hat garden gnome statue, about 4.5k triangles, one 1024px WEBP texture (baseColor), about 370 KB.
- Units: metres. 0.5 m tall, feet at y=0, centred on X/Z, front faces glTF +Z.
- Source: "Gartenzwerg" by Tauberstein on Meshy, licence CC0: https://www.meshy.ai/posts/0199e482-7749-78a4-937d-6019638b4153
- Reduced from 552k triangles in Blender (weld, decimate, 1K texture, matte material).

Use it as a yard/garden decoration (Hoofington front gardens). It is a static prop: no rig, no animation. Render it with its texture (do not bake it into vertex colours).
